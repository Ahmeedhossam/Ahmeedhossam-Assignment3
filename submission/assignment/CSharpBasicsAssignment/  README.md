# CSharp Basics Assignment

A .NET 10 console application covering C# fundamentals, types, casting, memory models (stack vs heap), and scopes.

## Project Files
- **Program.cs**: Main entry point and logic tests.
- **Order.cs**: Class demonstrating reference type behavior.
- **STACK_HEAP.md**: Memory diagrams.
- **ANSWERS.md**: Short conceptual answers.

## How to run
1. Open the terminal in the project folder.
2. Run `dotnet build`
3. Run `dotnet run`
